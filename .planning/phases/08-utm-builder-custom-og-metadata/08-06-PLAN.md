## Phase Goal

**As a** dashboard user managing campaign links, **I want to** attach UTM parameters and custom social-preview metadata to a short link and see exactly what the final URL and the social card will look like before I save, **so that** my campaign traffic is attributed correctly and my links preview the way I intend — without Kurzly ever fetching the destination.

> Derived from the ROADMAP Phase 8 `**Goal:**` line into user-story shape (MVP framing), matching the Phase 7 precedent.

<objective>
Close the loop: connect the form sections built in 08-04 and 08-05 to the API client built in 08-01, map the five new server error codes to their locked inline messages, and deliver UI-SPEC Surfaces C and D — the „UTM"/„OG" attribute badges in the links table and the two chips on the link detail page.

Purpose: Until this lands, the form sections have no parent to submit through and the user has no signal on a saved link that metadata is set.
Output: Error-code mappings, payload threading in both parent views, two badges, two chips.
</objective>

|----------|-------------|

| API error body → rendered message | A server error code selects which locked message is shown inline |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-ERR-ECHO | Information Disclosure | mapLinkFormError | medium | mitigate | The mapper selects from fixed local message constants keyed on the error code; no server-supplied string is rendered into the UI |
| T-08-CLEAR-DROP | Tampering | parent payload forwarding | medium | mitigate | Both parents forward null through untouched rather than collapsing it with a nullish fallback; explicit tests cover the clear path on both views |
| T-08-BADGE-LEAK | Information Disclosure | badges and chips | low | mitigate | Badges and chips report only that metadata exists; they render no value and no destination |
| T-08-DETAIL-LEAK | Information Disclosure | detail destination line | low | mitigate | The line keeps rendering the stored target only; a test asserts no UTM parameter is appended there (UI-08-07) |
