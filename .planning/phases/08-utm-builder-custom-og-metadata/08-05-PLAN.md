<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user keystrokes → browser image request | A typed URL becomes an image source the visitor's own browser fetches |
| form state → PATCH/POST payload | Typed OG values leave the browser for the API |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-IMG-SCHEME | Tampering | preview image binding | high | mitigate | The source is bound only after the value parses as an absolute http or https URL; a javascript or data value never becomes a source, and the server-side rejection in plan 08-01 remains the authoritative gate |
| T-08-IMG-BEACON | Information Disclosure | per-keystroke image requests | medium | mitigate | The binding is debounced and parse-gated, so partial hosts are never contacted; the request that does fire goes to a URL the user themselves typed |
| T-08-SSRF-CLIENT | Information Disclosure | preview architecture | high | mitigate | Structural: the preview never asks the server to fetch anything — no new API call is introduced by this plan (D-08-04) |
| T-08-CARD-LEAK | Information Disclosure | card domain line | medium | mitigate | The domain line derives from the selected short-link domain, never from the target URL, matching the product-wide no-leak posture (UI-08-06) |
| T-08-CARD-XSS | Tampering | card text rendering | medium | mitigate | Title, description and domain render as Vue text interpolation, never with a raw-HTML directive |
</threat_model>
