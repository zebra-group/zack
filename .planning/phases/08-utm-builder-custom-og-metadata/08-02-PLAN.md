## Phase Goal

**As a** dashboard user managing campaign links, **I want to** attach UTM parameters and custom social-preview metadata to a short link and see exactly what the final URL and the social card will look like before I save, **so that** my campaign traffic is attributed correctly and my links preview the way I intend — without Kurzly ever fetching the destination.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored Link fields → rendered HTML | Owner-typed OG values are interpolated into a public HTML document served to crawlers |
| stored Link fields → Location header | Owner-typed UTM values are assembled into the redirect destination |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-XSS-OG | Tampering | renderBotOgPage interpolation | high | mitigate | Every custom value routed through the existing `escapeHtml` before entering a meta content attribute; no raw interpolation added |
| T-08-OGIMG-SCHEME | Tampering | og:image emission | high | mitigate | Render-time absolute-http(s) guard via the WHATWG URL parser, on top of plan 08-01's write-time rejection |
| T-08-SSRF-RENDER | Information Disclosure | og:image handling | high | mitigate | Structural: the render path contains no fetch/request of the image URL (D-08-04); it is emitted as an attribute only |
| T-08-OPENREDIR-UTM | Tampering | applyUtmParams | high | mitigate | Only `searchParams` is mutated; scheme/host/path are never assigned — same structural guarantee `mergeQuery` already carries |
| T-08-QUERY-INJECT | Tampering | UTM value encoding | medium | mitigate | Encoding delegated entirely to `URLSearchParams`; no hand-rolled `&`/`=` assembly, so a typed ampersand cannot add a parameter |
| T-08-OG-LEAK | Information Disclosure | BotOgPageCtx | medium | mitigate | The context type gains only owner-typed text fields; it still carries no destination field, preserving the file's structural no-leak guarantee |
</threat_model>
