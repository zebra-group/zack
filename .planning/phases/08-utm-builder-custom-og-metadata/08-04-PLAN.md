## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user keystrokes → rendered preview | Typed values are interpolated into visible text inside the dashboard SPA |
| form state → PATCH/POST payload | Typed values leave the browser for the API |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-PREVIEW-NET | Information Disclosure | live preview | high | mitigate | The preview is a pure computed over local refs; no fetch is introduced, so neither the destination nor the campaign names are sent anywhere while typing (D-08-04, UI-08-10) |
| T-08-PREVIEW-XSS | Tampering | preview rendering | medium | mitigate | The preview is rendered as Vue text interpolation, never with a raw-HTML directive, so a typed angle bracket cannot become markup |
| T-08-CLEAR-SEMANTICS | Tampering | submit payload assembly | medium | mitigate | The keep-versus-clear ternary is centralised in one helper and covered by explicit tests, so an emptied field cannot silently persist its old server-side value |
| T-08-CLIENT-TRUST | Tampering | maxlength attributes | low | accept | The length caps in the form are convenience only; plan 08-01's server-side validation is the authoritative boundary and is independently tested |
</threat_model>
