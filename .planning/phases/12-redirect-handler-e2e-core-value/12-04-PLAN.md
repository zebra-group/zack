<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Crawler/bot → redirect handler | A bot must receive only owner-authored OG metadata, never the real destination (protects a gated target from crawler-side disclosure, D-06). |
| Visitor query string → final redirect target | Visitor-supplied query params must be able to APPEND only; they must never rewrite the owner's target scheme/host/path or override owner UTM (open-redirect / attribution-hijack surface). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-BOT-LEAK | Information Disclosure | `renderBotOgPage` / `if (bot)` branch | high | mitigate | Bot-branch tests assert 200-with-custom-OG and `assertNoLeak(target)` for normal, protected, and expired links, proving a crawler never receives the destination even across gates (D-06/D-08-03). |
| T-12-OPENREDIR | Tampering | `mergeQuery` / `applyUtmParams` composition | high | mitigate | Merge tests assert target-wins (visitor appends only, owner UTM overrides) and that a forwardQuery-off link ignores visitor params, proving the visitor cannot rewrite the destination (D-13/D-08-02). |
| T-12-SC | Tampering | npm/pip/cargo installs | low | accept | Zero new packages this phase — no supply-chain surface. |
</threat_model>
