<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → redirect handler | Anonymous, attacker-controlled Host/slug/UA/cookie/body on every request |
| handler → stored target | Protected/expired target must not cross to the client pre-check |
| verify endpoint → password compare | Brute-force surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-XSS-SLUG | Tampering / Information Disclosure | slug echoed into 404/password/expiry HTML | high | mitigate | All rendering via publicHtml's escapeHtml (05-03); integration test requests a `<script>` slug and asserts entity-escaped 404 |
| T-05-NOLEAK | Information Disclosure | protected/expired responses | high | mitigate | Precedence classifies before rendering; no target passed to any pre-unlock renderer; automated no-leak canary asserts absence in body AND headers (D-14) |
| T-05-BOT-LEAK | Information Disclosure | bot branch on protected/expired | high | mitigate | Bot short-circuit always renders generic OG 200, never 302, never the human page, never the target (D-06) |
| T-05-BRUTE | Spoofing | POST /:slug/verify | high | mitigate | Per-(IP,host,slug) rate limit (D-15) + bcrypt per-guess cost; wrong password re-renders with no leak |
| T-05-COOKIE-FORGE | Tampering / Spoofing | unlock cookie replay/forgery | high | mitigate | Signed cookie bound to a digest of the current passwordHash (05-04); a stale cookie stops unlocking after a password change (asserted) |
| T-05-HOSTSPOOF | Spoofing | Host/X-Forwarded-Host | high | mitigate | Sole host entry is resolveActiveDomainByHost's deny-by-default exact-active match; fastify ≥5.10 is past CVE-2026-3635 |
| T-05-STALECACHE | Tampering (cached state) | any response | medium | mitigate | Cache-Control: no-store on every branch (D-18) |
</threat_model>
