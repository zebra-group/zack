| client form → API | Password/expiry/forwardQuery submitted for persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-PWPREFILL | Information Disclosure | edit-mode password field | high | mitigate | Password input never bound to a value; DTO carries only `passwordProtected` boolean (from 05-02); placeholder communicates "set" |
| T-05-KEEPCLEAR | Tampering | edit keep-vs-clear semantics | medium | mitigate | Blank = keep (undefined); only the explicit "entfernen" action emits null to clear — proven by component tests |
| T-05-CLIENTAUTHZ | Elevation of Privilege | form is client-tier only | low | accept | Server independently re-validates/authorizes every create/update (Phase 4, T-04-UIAUTHZ); the form is convenience only |
</threat_model>
