<objective>
Build the single dependency-free server-rendered HTML layer (D-09) shared by all four public response types — password page (UI-04), expiry page (UI-05), generic 404 page (D-11), and the bot-OG head (D-05) — with an `escapeHtml()` helper applied to every user-controlled interpolation. The incoming URL slug is attacker-controlled on every request (including a 404), so escaping is the phase's single highest-value injection guard (RESEARCH Pitfall 1). No page ever contains a link's target URL.

Purpose: The redirect route (05-06) calls these renderers; isolating them here (pure, unit-testable, no Fastify) lets the security-critical escaping + copy contract be proven without HTTP. Visual/token fidelity follows 05-UI-SPEC exactly (tokens copied 1:1 from tokens.css / AuthErrorView.vue).
Output: `lib/publicHtml.ts` with `escapeHtml` + four render functions; unit tests for escaping, locked copy, no-leak, and bot-OG structure.
</objective>
