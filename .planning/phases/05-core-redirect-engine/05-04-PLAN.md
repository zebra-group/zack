<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client cookie → server | Replayed/forged unlock cookie attempts to bypass the password gate |
| incoming query → redirect target | Attacker-supplied query merged onto the stored target |
| client UA → branch selection | Spoofable UA drives the bot/OG vs human branch |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-COOKIE-FORGE | Tampering / Spoofing | unlock cookie | high | mitigate | Payload = digest of current passwordHash + @fastify/cookie `signed:true`; a forged/stale cookie fails signature or payload equality (Pattern 4) |
| T-05-OPENREDIR | Tampering | mergeQuery | medium | mitigate | Only appends query keys onto the already-validated target; scheme/host/path immutable (D-13, structurally no open redirect) |
| T-05-PRECEDENCE | Information Disclosure | resolveLinkState | high | mitigate | Expiry checked first + unconditionally; an expired+protected link is always "expired", never leaks via the protected branch (D-14) |
| T-05-RLKEY | Spoofing | verify rate-limit key | medium | mitigate | keyGenerator keys on IP+host+slug so cross-domain same-slug brute force cannot collapse buckets (Pitfall 4) |
</threat_model>
