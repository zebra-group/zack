## Phase Goal

**As a** team operator, **I want to** sign in to Kurzly with a magic link and land in a themeable dashboard shell whose every domain-scoped action is authorized server-side, **so that** I can manage short links securely on my own infrastructure.

> Derived faithfully from the ROADMAP Phase 2 Goal + Success Criteria (no invented scope). This plan is the enabling first step: it vets and installs the new auth/security dependencies and adds the first-admin bootstrap ENV var that the whole magic-link flow depends on.

Vet and install this phase's four new packages behind a blocking human supply-chain checkpoint, then extend the existing fail-fast ENV validator with `INITIAL_ADMIN_EMAIL` (D-01) so a fresh deployment cannot boot without naming its first admin.

</objective>
