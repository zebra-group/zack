## Phase Goal

**As a** team member, **I want to** manage all my links in the dashboard — search/filter the list, copy a link's full URL, open its detail page, edit it (with a slug-change warning), delete it, and bulk-import via CSV with a live preview — **so that** I have a complete, pixel-accurate Links workspace. (Phase 4 Success Criteria 2 & 3 + LINK-03/04/05/06/07/08, UI-06.)

Deliver the Links frontend slice: extend the typed API client, register the three routes (replacing the `/links` ComingSoon placeholder), and build the three screens per 04-UI-SPEC.md against the endpoints from 04-02/03/04. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user → Vue SPA | User-entered target/slug/CSV pass through the client, but the client is never the access boundary — the API re-authorizes/re-validates every request |
| SPA → same-origin API | The httpOnly session cookie auto-attaches; the UI shows only what the scoped API returns |

## STRIDE Threat Register (ASVS L1, block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-UIAUTHZ | Elevation of Privilege | client-side scoping | high | mitigate | The list, domain filter, and detail render ONLY what the scoped API returns; the UI never fabricates access — server-side scopedDomainIds/requireDomainAccess (04-02/03) is the real boundary, re-proven by the backend suites, not this UI. |
| T-04-COPYLEAK | Info Disclosure | copy full URL | low | accept | Copy composes the public short URL `https://{domain}/{slug}` client-side (no secret); the destination is not exposed beyond what the authorized user already sees in their own list. |
| T-04-PREVIEWDRIFT | Tampering | client-side preview | medium | mitigate | The import preview renders only the backend ImportPreviewResult — no client-side CSV re-parse/re-validate that could disagree with the commit (D-05). |
| T-04-SC | Tampering | npm/pip/cargo installs | n/a | N/A | No installs this plan (frontend uses existing @vue/test-utils + Vite; no new deps). |
</threat_model>
