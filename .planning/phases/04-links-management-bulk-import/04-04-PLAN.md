## Phase Goal

**As a** team member, **I want to** bulk-import links from a CSV (ziel_url, slug, domain) with a live "N valid / M skipped" preview before committing, **so that** I can load many links at once while every row is validated exactly as a manual create would be. (Phase 4 Success Criterion 3 + LINK-08, D-01/D-05.)

<objective>
Deliver the CSV bulk-import slice as a two-phase (preview → commit) feature whose entire correctness rests on D-01: preview and commit share one `runImport` function that parses once and loops sequentially, differing only by whether each row calls `previewLink` (dry-run) or `createLink` (the same insert the manual-create route uses). This makes "bulk cannot bypass validation" a structural fact provable by test — the single most important test in the phase queries the DB directly after a commit to assert zero rows leaked for any skipped row.

Purpose: The whole phase is framed around "no bypass, no smuggled invalid data." The import must reuse the exact validation/authorization/reserved-slug rules of manual creation, never a parallel `createMany` write path (RESEARCH Pitfall 1).
Output: `runImport`/`previewImport`/`commitImport` + row/skip helpers in `lib/links.ts`, the two import endpoints in `routes/links.ts`, and the no-bypass integration proof.
</objective>
