Deliver AUTH-E2E-05 as a genuine TDD RED→GREEN pair with a real production code fix. Per 13-RESEARCH.md's code-verified finding (traced line-by-line through installed better-auth@1.6.23), the SSO-after-invite merge that ROADMAP success criterion 4 requires does NOT currently work: `createAuth()` sets no `account.accountLinking` config, so better-auth's default `requireLocalEmailVerified: true` rejects linking an OAuth login to an invited User whose `emailVerified` is still false. Purpose: Close AUTH-E2E-05 and land the code change it depends on, honoring D-01, D-09-04 (invite shape), D-10-04 (least-privilege).
Output: The appended E2E merge test, an integration-level merge test, and the auth.ts fix.
