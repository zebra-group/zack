<objective>
Build the three privacy-preserving transforms that convert a raw redirect request into storable, PII-free tracking fields, plus the Docker build step that bakes the DB-IP Country Lite `.mmdb` into the image (D-02, air-gapped-by-default):

- `normalizeReferrer` (D-07) — `Referer` header → source host only (path/query discarded), null for missing/malformed.
- `getCountryForIp` (D-04, TRACK-03) — local `.mmdb` lookup via `maxmind`, lazy singleton, degrades to null (never throws, never crashes boot) on private/unmapped IPs or a missing DB.
- `computeVisitorHash` + `resolveDailySalt` (D-06/D-08) — daily-rotating HMAC-SHA256 visitor hash; only the hash is ever persisted, never raw IP/UA; salts rotate per UTC day so visitors are not re-identifiable across days.

Purpose: the raw materials for a privacy-first click row — none of which ever calls a third party.
Output: three tested helper modules + the GeoIP DB baked into the runtime image.
</objective>
