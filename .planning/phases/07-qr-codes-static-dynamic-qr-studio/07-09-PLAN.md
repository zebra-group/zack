## Phase Goal

**As a** dashboard user, **I want to** create static and dynamic QR codes for my short links — with a centered logo, custom color and rounded-module styling, re-pointable dynamic targets that keep a printed code valid, and a visible scan count — **so that** I can print scannable codes that keep working even after I change where they point.

> Derived from the ROADMAP Phase 7 `**Goal:**` line into user-story shape (MVP framing). This slice adds the second entry point (Surface B): creating/opening a static QR straight from a link's detail page.

<objective>
Add the second QR entry point (UI-SPEC Surface B): a "QR-Code" action button on `LinkDetailView.vue` that either deep-links to an existing static QR or creates one on the spot and navigates to it — no dialog, mirroring the "+ Dynamischer QR" instant-action philosophy. This closes the QR-01 static-create flow from the link context.

Purpose: Give users a static QR for any link exactly where they manage that link.
Output: The extended action row + navigation side-effect + a component test.
</objective>
