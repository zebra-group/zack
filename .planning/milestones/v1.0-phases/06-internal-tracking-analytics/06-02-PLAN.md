<objective>
Deliver TRACK-01's persistence half end-to-end through the existing single authorized write path, and lay the complete tracking data model (ClickEvent + ScanSource + DailySalt) with the [BLOCKING] migration every later plan compiles and queries against.

`trackingEnabled` threads through `validateLinkInput`/`createLink`/`updateLink` exactly like `forwardQuery` did in Phase 5 — a plain boolean, no new validation branch, Prisma column default `true` covers create-time default (RESEARCH Pattern 1, 06-PATTERNS.md). `lifetimeClicks` (D-13 pruning-resistant counter) is added now with default 0 but incremented only later (06-04). The event model is defined now so 06-03/06-04/06-05 never reopen the schema.

Purpose: a link owner's tracking preference is durably persisted (default on) through the one no-bypass path, and the event tables exist.
Output: migrated schema, threaded write path, extended DTOs.
</objective>
