<objective>
Replace `LinkDetailView.vue`'s static "Statistiken — bald verfügbar" placeholder with the real per-link analytics surface (Surface A), delivering TRACK-04 and the detail-page half of TRACK-01:

1. An always-visible "Internes Tracking" card with the accent toggle — clicking flips tracking with an immediate optimistic state change + a background PATCH through the existing `updateLink` client (D-15, single write path); on failure it reverts and toasts.
2. A data section rendering exactly one of four mutually-exclusive states: tracking-off dashed empty state, loading skeleton, zero-data state (all card shells with 0/"–"/"Keine Daten"), or the full data state (3 stat cards, 30-bar chart with per-bar tooltips, referrer + country progress lists) fed by a new `getLinkAnalytics` API client.

Purpose: a link owner opens a link and sees its private click analytics, and can toggle tracking inline.
Output: the api client + the reworked detail view, tested.
</objective>
