<objective>
Build the read side of analytics: a new `lib/analytics.ts` doing live SQL aggregation (D-10) and two authenticated endpoints backed by it, powering the per-link section (TRACK-04) and the global overview (TRACK-05).

Per-link: total (from the pruning-resistant `lifetimeClicks`, D-13), 30-day `date_trunc`-bucketed zero-filled series (`generate_series` LEFT JOIN — RESEARCH Pattern 5), last-7-day count, top referrers, top countries. Global: 30-day clicks, unique visitors (`COUNT(DISTINCT visitorHash)`), active links (a Link count, independent of clicks), QR scans (`COUNT(source='qr')` → 0 this phase, D-14), top links, top referrers — all scoped to the caller's own domains via `scopedDomainIds`.

Every query is parameterized `Prisma.sql` (never string-concatenated — SQL injection, ASVS V5). The per-link endpoint reuses the `resolveOwnedLink` IDOR shape (404 for both not-found and forbidden). The global endpoint is session-gated and domain-scoped (full member-role enforcement + denial suite deferred to Phase 9 — an intentional, documented gap).

Purpose: the server can answer "how is this link / my whole account doing" privately and safely.
Output: analytics service + two endpoints + DTOs, registered in app.ts.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dashboard user → analytics API | authenticated but a caller may attempt to read resources outside their domain scope (IDOR) |
| linkId/date params → SQL | untrusted values must be parameterized, never concatenated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-SQLI | Tampering | lib/analytics.ts | high | mitigate | Exclusively tagged-template `Prisma.sql`/`$queryRaw`; grep proves no `$queryRawUnsafe`; linkId/domainIds/date ranges parameterized (ASVS V5) |
| T-06-IDOR | Information Disclosure / Elevation of Privilege | GET /api/links/:id/analytics | high | mitigate | Reuses the resolveOwnedLink scopedDomainIds+findFirst shape; 404 for both not-found and forbidden (no existence oracle) |
| T-06-GLOBALSCOPE | Information Disclosure | GET /api/analytics | medium | mitigate | Global aggregation constrained to scopedDomainIds (caller's own domains), not the whole instance; full member-role enforcement deferred to Phase 9 (documented intentional gap) |
| T-06-EMPTY | Information Disclosure | getGlobalAnalytics | low | mitigate | Empty domainIds short-circuits to zero/empty results — no cross-tenant leak, no invalid SQL |
</threat_model>
