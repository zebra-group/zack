# Phase 06 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Deckt ab:** Drei Erweiterungen des bestehenden Dashboard-SPA (TRACK-01…TRACK-05) — (A) Per-Link-Analytics-Sektion in `LinkDetailView.vue` (ersetzt den Phase-4-Statistik-Platzhalter), (B) neue globale Analytics-Ansicht `AnalyticsView.vue` (ersetzt `ComingSoonView` unter `/analytics`), (C) Tracking-Toggle in `LinkFormModal.vue` (footer-left, Default an) + „Tracking aus"-Badge/Klicks-Spalte in der bestehenden Links-Tabelle (`LinksView.vue`).
