## Phase Goal

**As a** dashboard user, **I want to** create static and dynamic QR codes for my short links — with a centered logo, custom color and rounded-module styling, re-pointable dynamic targets that keep a printed code valid, and a visible scan count — **so that** I can print scannable codes that keep working even after I change where they point.

> Derived from the ROADMAP Phase 7 `**Goal:**` line into user-story shape (MVP framing).

<objective>
Expose the QR management HTTP surface (`apps/api/src/routes/qrCodes.ts`) — authenticated, domain-scoped, mass-assignment-guarded — mirroring `routes/links.ts` and `routes/analytics.ts` exactly, plus the on-demand render endpoints that feed both the Studio live preview and the list thumbnails. All mutations route through 07-04's single write path; all rendering routes through 07-03's shared core.

Purpose: A thin, IDOR-safe controller layer with a dedicated rate-limit bucket for the bursty debounced-preview traffic (RESEARCH Open-Question 2).
Output: `routes/qrCodes.ts`, new rate-limit constants, app.ts registration, and route-level integration tests.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-MASS | Tampering | Zod schemas on POST/PATCH | high | mitigate | Only allowlisted fields read off parsed.data; never request.body directly; code/lifetimeScans/variant server-owned |
| T-07-IDOR | Elevation of Privilege | resolveOwnedQrCode on GET/PATCH/render | high | mitigate | membership-first scopedDomainIds join; identical-404 for not-found and forbidden |
| T-07-LOGO-MIME | Tampering | logo upload validation | high | mitigate | Server-side size cap + magic-byte check + SVG→PNG rasterization via normalizeLogo before storage; client Content-Type never trusted |
| T-07-DOS-RENDER | Denial of Service | debounced preview render endpoints | medium | mitigate | Dedicated QR_RENDER_RATE_LIMIT bucket instead of the permissive global default (RESEARCH Open-Question 2) |
| T-07-AUTHZ | Spoofing | /api/qr-codes* auth | medium | mitigate | Reuses better-auth session check via resolveUserId (no new auth mechanism) |
</threat_model>
