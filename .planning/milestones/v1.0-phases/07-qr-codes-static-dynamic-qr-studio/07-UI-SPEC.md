# Phase 07 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Deckt ab:** Der neue `/qr-codes`-Screen (ersetzt `ComingSoonView`) als **QR-Codes-Liste + QR-Studio** nebeneinander — statische QR-Codes (1:1 an einen bestehenden Link gebunden) und dynamische QR-Codes (eigene `/q/:code`-Kurz-URL, jederzeit umstellbares Ziel, sichtbare Remap-Historie), Logo-Overlay (Standard-Platzhalter + eigener Upload), Farb-/Rundungs-Styling mit Live-Preview, PNG/SVG-Export, Scan-Zähler pro Code. Zusätzlich: ein neuer „QR-Code"-Aktions-Button in `LinkDetailView.vue` als zweiter Einstiegspunkt (statische QR-Erzeugung), sowie Empty/Loading/Error-Zustände für die neue Liste.

**Nicht in diesem Contract:** Bulk-QR-Erzeugung, Nicht-Link-QR-Payloads (vCard/WLAN), Print/PDF-Layout-Bögen, animierte/Gradient-QR-Styles (alle laut CONTEXT.md dauerhaft out-of-scope), domain-scoped Member-Sichtbarkeit der QR-Endpunkte (Phase 9), QR-Code-Umbenennen/-Löschen (nicht in QR-01…07 gefordert, siehe Copywriting-Contract-Begründung).

### Standing Sign-Off (unverändert aus Phase 2–6)

- Requirement **UI-03**, Locked Decision **D-04 (Phase 2)**, `.claude/CLAUDE.md` **„UI-Treue: High-Fidelity … pixelgenau nach Prototyp."** — stehende Projekt-Owner-Freigabe für 1:1-Reproduktion der Prototyp-Tokens, auch für Phase 7. ### Ausdrücklich gewaiverte Heuristiken (weiterhin gültig)

1. **„Maximal 4 Font-Größen"** — gewaivert. Phase 7 führt **keine neue Font-Größe** ein — jede hier genutzte Größe (10px/11px/11.5px/12px/12.5px/13px/13.5px/14px/19px/21px) stammt aus der in Phase 2 gesperrten Vollskala.

3. **„Alle Spacing-Werte müssen Vielfache von 4 sein"** — gewaivert. Phase 7 übernimmt die exakten Prototyp-Feinwerte des QR-Codes-Screens (Karten-Padding `14px 16px`, Thumbnail 46×46px, Studio-Panel 360px/18px-Padding, große Vorschau 196×196px/21 Module, Swatch 22×22px u. a. — siehe Spacing Scale unten).
