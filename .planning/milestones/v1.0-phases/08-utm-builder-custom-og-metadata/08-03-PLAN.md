## Phase Goal

**As a** dashboard user managing campaign links, **I want to** attach UTM parameters and custom social-preview metadata to a short link and see exactly what the final URL and the social card will look like before I save, **so that** my campaign traffic is attributed correctly and my links preview the way I intend — without Kurzly ever fetching the destination.

> Derived from the ROADMAP Phase 8 `**Goal:**` line into user-story shape (MVP framing), matching the Phase 7 precedent.

<objective>
Wire 08-02's two pure helpers into the two public redirect handlers so the feature becomes observable to a real visitor: UTM parameters land on the destination (META-01, D-08-02) and crawlers receive the owner's OG values (META-02, D-08-03). Both handlers must change identically — any drift between `/:slug` and `/q/:code` is the exact failure mode Phase 7 spent effort avoiding.

Purpose: This is the slice where a saved UTM parameter actually changes where a visitor lands.
Output: Two edited route branches per handler, plus integration coverage on both.
</objective>
