<objective>
Create the ONE genuinely-new asset this phase needs: a tiny, well-tested CSV-fixture builder `apps/e2e/src/csv.ts` (`buildImportCsv` + `IMPORT_CSV_HEADER`) that both CSV-import specs (14-03/14-04) will consume to construct runtime CSV strings whose slugs are computed per-test.
