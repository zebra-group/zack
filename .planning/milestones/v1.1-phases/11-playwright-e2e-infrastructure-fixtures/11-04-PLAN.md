## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test runner -> db :5433 | Direct seed/reset writes bypassing the API tier (setup/teardown plumbing only) |
| test runner -> Mailpit REST :8025 | Reading captured magic-link emails |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-03 | Elevation of Privilege | seeded Member fixture | high | mitigate | seedBaseline seeds the Member with EXACTLY one DomainMembership at role `member` and `accountRole: member` — never account-admin, never extra memberships "for convenience"; downstream AUTHZ specs (Phase 17) depend on this being a real least-privilege shape (RESEARCH Security Domain V4). |
| T-11-06 | Tampering | direct DB seed/reset via Prisma raw exec | medium | mitigate | resetDb only truncates the mutable file-scoped tables and runs under a pg_advisory_lock so parallel workers cannot corrupt each other's rows; User/Domain/Session are never truncated mid-run (preserves session integrity). |
| T-11-07 | Information Disclosure | cross-worker email theft | high | mitigate | findMagicLinkUrl retrieves strictly via recipient-scoped search and hard-asserts the To address before returning — a worker can never consume another worker's magic link (RESEARCH Pitfall 1). |
</threat_model>
