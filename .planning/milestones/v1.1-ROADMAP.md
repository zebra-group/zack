# Milestone v1.1: E2E Test Coverage

**Status:** ✅ SHIPPED 2026-07-25
**Phases:** 11-17
**Total Plans:** 35

## Overview

Add a real Playwright E2E suite covering every critical v1.0 user flow, run against the built Docker image in production shape, complementing the existing 540 API + 256 web Vitest tests. No new product features — the "requirement" grain is E2E test scenario. Sequenced infrastructure-first so shared foundation bugs (email polling, DB isolation, rate-limiting) are solved once before any flow coverage is written.

Executed **fully autonomously** across all 7 phases after the user handed off with "continue autonomously, I'm AFK" — no user checkpoints after the initial instruction.

**Success Criteria** (what must be TRUE):

**Success Criteria** (what must be TRUE):
1. The magic-link round-trip passes end-to-end, and a consumed/expired/invalid token is rejected with no session created. [AUTH-E2E-01, AUTH-E2E-02]
2. A non-invited email address never receives a session. [AUTH-E2E-03]

## Milestone Summary

**Key Decisions:**
- E2E harness runs against the real built Docker image in production shape, never split dev servers — chosen specifically so infrastructure bugs (rate-limiting, session handling, content-type parsing) that only manifest in the deployed topology get caught.
- `E2E_COMPOSE_OVERLAY` marker env var introduced to distinguish "this boot IS the E2E overlay" from real production, since `NODE_ENV=production` alone can't (the E2E stack deliberately runs `NODE_ENV=production` for topology fidelity).
- Fixture-layer reuse was strictly additive across all 7 phases (db.ts → links.ts → qr.ts/users.ts → team specs) — no phase reinvented an earlier phase's fixture pattern.
- workflow.use_worktrees=false for this milestone — all executor agents ran sequentially on the main working tree.

**Issues Resolved (real production bugs found via live E2E, not static review):**
- Phase 11/12: NODE_ENV crash-loop, better-auth's internal rate limiter conflict, app's-own-host 404 bug, password-verify form's missing content-type parser.
- Phase 13: empty OAuth `scope=` parameter, missing `account.accountLinking` config, undocumented second SSO-merge security gate.

**Issues Deferred (non-blocking, see v1.1-MILESTONE-AUDIT.md):**
- Full-suite rate-limit-bucket ceiling when running all `tests/authed/` specs in one invocation (D-17-05-01).
- Cross-file DB-truncate race, mitigated by retries since Phase 12, never eliminated by design choice.
- Duplicated retry/skip boilerplate across spec files (cosmetic, four-times-flagged).
